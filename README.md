# ShotOpt

A screenshot app for my OptOut community vault.

Turn plain screenshots into polished images: gradient and mesh backgrounds, device
and window mockup styles, real 3D perspective tilt, and one-click PNG / JPG / WEBP
export.

**Everything runs in your browser.** Images are never uploaded — there is no
backend, no analytics, no accounts, and no third-party requests of any kind. The
`Content-Security-Policy` in `_headers` locks the page to same-origin, so that
claim is enforced by the browser rather than just promised.

## Features

- Drag-and-drop, paste (⌘V) or file-pick — up to 3 images at once
- 15 mockup styles: Card, Glass, Inset, Outline, Retro, Stack, macOS Window, Browser…
- 140+ backgrounds across 10 categories, plus custom colour, your own image,
  transparent, and **Magic** (a palette derived from your screenshot)
- 26 one-click **templates** (product promo, UI showcase, minimal, abstract),
  including animated ones — thumbnails preview your own screenshot live
- **Motion**: 8 animation presets (push, pan, sweep, showcase orbit, float…)
  with live preview and in-browser **WebM video export**
- **VFX**: Cinematic (teal & orange + letterbox), VHS, Noir, Vintage, Dream —
  all GPU-accelerated, with an intensity dial
- **Scenes**: floor, glow, glossy 3-D spheres, blobs, prisms, clouds and a
  podium with perspective grid — props take their colours from the background
  and cast soft shadows that follow the global light angle
- 8 shadow types with opacity, size, light angle and distance
- GPU-accelerated perspective: tilt X/Y, rotate, zoom, offset
- Direct manipulation on the canvas: drag the screenshot to move it, grab the
  corner handles to resize
- 12 layout presets with live thumbnails
- 23 canvas sizes including LinkedIn, X, Open Graph, Instagram and Story presets
- Grain, vignette, one-click background blur, text **or logo** watermark
- Up to 4× export in PNG, JPG or WEBP at high encoder quality
- Undo/redo, settings persistence, installable as a PWA, works offline

## Running it locally

No build step, no dependencies, no package manager. Either open `index.html`
directly, or serve the folder to get offline caching and clipboard support:

```bash
python3 -m http.server 8787
```

Then visit `http://127.0.0.1:8787`.

> Copy-to-clipboard and the service worker require a secure context, so they are
> active on `https://` and `localhost` but not when opening the file from disk.
> Everything else works either way.

## Deploying to Cloudflare Pages

Connect the repository and use these settings:

| Setting | Value |
| --- | --- |
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `/` |

Nothing compiles — Pages serves the files as-is, and `_headers` applies the
security and caching rules.

## Project layout

| File | Purpose |
| --- | --- |
| `index.html` | The entire app — markup, styles and logic in one file |
| `sw.js` | Service worker: offline shell cache, network-first for updates |
| `manifest.webmanifest` | PWA metadata so it can be installed |
| `icon.svg` | Favicon and app icon |
| `og.jpg` | Social preview card (generated by the app itself) |
| `_headers` | Cloudflare Pages security and caching headers |

## Updating

After changing `index.html`, bump `CACHE` in `sw.js` (e.g. `shotopt-v2`) so
returning visitors drop the old cached copy.

## Browser support

Chrome, Edge, Safari and Firefox (current versions). Perspective tilt uses WebGL
where available and falls back to a CPU renderer otherwise — the footer shows
which one is active.
